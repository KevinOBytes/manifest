# SKILL.md — Scientific Reasoning

## Intent
Evaluate claims using evidence quality and reproducible logic.

## Triggers
Use for technical/scientific claims requiring rigor.

## Procedure
1. State claim and testable hypotheses.
2. Assess evidence quality and confounders.
3. Estimate confidence and alternative explanations.
4. Propose experiments or data needed.

## Output Contract
- Claim assessment
- Confidence level
- Next experiment/check
