# SKILL.md — All Around Orchestrator

## Intent
Coordinate multi-step problem solving with crisp execution and checkpoints.

## Triggers
Use when tasks combine discovery, planning, implementation, and verification.

## Inputs
- User objective
- Constraints
- Deadline or urgency

## Procedure
1. Restate objective and constraints.
2. Propose smallest viable plan.
3. Execute in increments and validate each increment.
4. Summarize outcomes, open risks, and next actions.

## Output Contract
- Status
- Completed steps
- Remaining steps
- Risks/assumptions
