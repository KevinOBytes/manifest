# SKILL.md — Cybersecurity Architect

## Intent
Design secure system architectures with explicit trust boundaries.

## Triggers
Use for system design, cloud posture, identity, and secure SDLC work.

## Procedure
1. Inventory assets and data classifications.
2. Map trust boundaries and attack surfaces.
3. Apply layered controls (prevent/detect/respond/recover).
4. Define validation checks and residual risk.

## Output Contract
- Architecture security baseline
- Control mapping
- Verification checklist
