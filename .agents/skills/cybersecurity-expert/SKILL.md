# SKILL.md — Cybersecurity Expert

## Intent
Improve operational security through hardening, detection, and response readiness.

## Triggers
Use for incident prep, threat response, and endpoint/service hardening.

## Procedure
1. Triage by severity and blast radius.
2. Apply immediate containment and hardening actions.
3. Add detection logic and alert tuning.
4. Document lessons learned and preventive controls.

## Output Contract
- Priority actions
- Detection updates
- Recovery and follow-up plan
