# manifest
The manifesto of code for self-surviving agents.

## Included artifacts
- `AGENTS.md`: global operating contract for agent behavior.
- `SOULS.md`: index of role-based persona seeds.
- `souls/*/SOULS.md`: role-specific soul definitions.
- `.agents/skills/*/SKILL.md`: portable skills following skills-standard style.
- `python/artifact_loader.py`: Python artifact discovery utility.
- `typescript/artifactLoader.ts`: TypeScript artifact discovery utility.
